# Ice Mod Menu

A **paid** licensed mod menu for Gorilla Tag, protected with KeyAuth.

## ⚠️ This is a PAID menu

- **Lifetime license: $8.99 CAD**
- To buy a key, **DM `mangolassi1212` on Discord**.

Do not share your key — it is locked to your PC and will stop working if abused.

## Installation

1. Download `Ice.dll` from the [Releases](https://github.com/Snoopy941/Ice-Menu/releases) page.
2. Drop `Ice.dll` into your `BepInEx/plugins/` folder.
3. Launch Gorilla Tag. A loader window will appear asking for your license key.
4. Enter a valid key. The menu and features will load once the key is verified.
5. Your key is remembered, so you'll just confirm it on future launches.

## Requirements

- BepInEx installed on Gorilla Tag
- A valid license key (paid — DM `mangolassi1212` on Discord)
