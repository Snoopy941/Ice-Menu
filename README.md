# Ice-Mod-Menu
**DISCORD: https://discord.gg/A8ts5d8Kr8**

A Gorilla Tag Mod Menu. 500+ mods. Overpowered. Fully Undetected. Fast. Reliable. Built to last. Free to skid.

# How to use
Simply go to releases, download the DLL and put it in your BepInEx plugins folder.

# How to compile
It assumes you have Gorilla Tag and BepInEx installed to the **default path**, if thats the case just open the project using Visual Studio and everything should be good.
